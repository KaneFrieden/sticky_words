# 12 November 2026: checking the input data

We wrote the script [`s00_verify_inputs_marie.py`](../../scripts/s00_verify_inputs_marie.py) to check that the raw Duolingo learning traces and the output location are available before beginning the analysis.

The script compares the raw file with the local `dataset_manifest.json`. The local file's size was 379,004,009 bytes, and the MD5 checksum also matched the value stored in that manifest (a manifest is a file that contains metadata about the dataset). The script also checked that the configured output location and the shared raw-data location did not overlap, which is important to avoid data conflicts.

In general, this check is supposed to show that the local file matches the manifest we predefined. It does not independently verify the manifest with the publisher during a run, neither does it check every data field.
