# Intermediate results — 13 November 2026

## Kane s01: selecting the data

We selected entries in which the learning language is English (`en`) and the interface language is Spanish (`es`). This is the largest language pair in the [Duolingo learning traces](https://doi.org/10.7910/DVN/N8XJME). However, the interface language does not tell us whether someone is indeed a native Spanish speaker, so we primarily use it to define a group in the data, not to make a claim about the learners' backgrounds.

The selection contains 3,641,179 of 12,854,226 entries (28.33%), from 31,735 learner IDs and 2,881 lexeme IDs. These numbers come from `subset_report.json`. At this point, we have not excluded any short time intervals or unusual lexeme descriptions.

The median time since the previous practice of an item is 0.484 days, or about 11.6 hours. 57.10% of entries have an interval shorter than one day. Our proposal suggested excluding these entries. Since that would remove more than half of this initial selection, we need to examine the choice carefully and later check how sensitive our results are to it. A short interval does not, by itself, tell us whether an entry definitely belongs to the same learning session, although it is of course a strong indicator, especially given Duolingo's practice design (streak).

Across the selected entries, `session_correct / session_seen` is 6,103,658 / 6,752,286 = 90.39%. This describes the overall observed answer accuracy; but it does not yet tell us how that accuracy changes with time or differs between words.

## Marie s02: inspecting lexeme descriptions

We then inspected the 2,881 distinct lexeme descriptions before building the word inventory. A description such as `boys/boy<n><pl>` contains a surface form (`boys`), a lemma (`boy`) and grammatical tags (`n`, `pl`). Each lexeme ID in our selection has one description.

The parser also marks descriptions that may need special treatment because they have different forms:

| Case                                              | Lexeme IDs | Entries | Example                                      |
| ------------------------------------------------- | ---------: | ------: | -------------------------------------------- |
| Wildcard                                          |        646 |  62,530 | `<*sf>/year<n><*numb>`                       |
| Shared pronoun lemma `prpers`                     |         15 | 278,639 | `we/prpers<prn>...`                          |
| Construction tag                                  |        298 |  48,956 | `have/have<vbhaver><pres><@present_perfect>` |
| Lemma outside our current word pattern            |          2 |  12,245 | `'s/'s<gen>`                                 |
| Construction tag in place of a regular word class |          1 |   7,441 | `you/prpers<@ij:thank_you>`                  |
| Description not fully parsed                      |          1 |     143 | `cannot/can<vaux><pres>+not<adv>`            |

These groups overlap. For example, the unusual `you/prpers` entry is also counted under `prpers`. For now, we keep both `cannot` and its original description rather than consiering it as a simple one-word form.

s02 has overall not excluded any entries. It is only there to classify, not filter.
